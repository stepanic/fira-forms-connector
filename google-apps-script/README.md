# Google Apps Script — FIRA integration

Multi-event GAS source. Each event has its own folder; build script merges
the event config with shared modules into one `Code.gs` per event, ready to
push to a separate Google Apps Script project via `clasp`.

## Layout

```
google-apps-script/
  events/
    badija-2026/Config.gs     # event config (CONFIG object)
    osijek-2026/Config.gs
    sibenik-2026/Config.gs
  modules/
    Mapping.gs                # main FIRA logic — onOpen, onCheckboxEdit, buildPayload, ...
    SplitPayment.gs           # advance + final invoice flow (opt-in per event)
  legacy/                     # v1 single-event flow, no longer used
  dist/                       # generated by build:gas — gitignored
    <slug>/
      Code.gs                 # merged: Config + Mapping (+ SplitPayment if enabled)
      appsscript.json         # GAS manifest
      .clasp.json             # clasp link to a specific GAS project (after first push)
```

`SplitPayment.gs` is included automatically when the event's `Config.gs`
defines `AKCIJA_AVANS:` in `COLUMNS`.

## Adding a new event

1. `mkdir google-apps-script/events/<slug>` (e.g. `zagreb-2026`)
2. Copy the closest existing `events/<slug>/Config.gs` (one-day regional
   event → `sinj-2026` / `varazdin-2026`; split payment → `badija-2026`), edit values
3. Put the **exact** response-sheet headers into `COLUMNS` — matching is exact,
   Google Forms leaves trailing spaces (`'Godina rođenja '`), and organizers name
   manual columns freely (Varaždin has `Uplate`, not `Uplata`). The Sheets API is
   disabled in the clasp GCP project and Drive export only has `drive.file`
   scope, so read headers from a browser tab on the Sheet:
   `fetch('/spreadsheets/d/<id>/export?format=tsv&gid=<gid>')`
4. `npm run build:gas` — confirms it builds
5. Create the **bound** GAS project from an empty dir:
   `clasp create --title <Name> --parentId <sheetId>` — **without `--type sheets`**:
   with `--type`, clasp ignores `--parentId` and creates a new empty Spreadsheet.
   The Sheet must be shared with the clasp account first.
6. `npm run push:gas -- <slug> <scriptId>` — first push creates `.clasp.json`
   inside `dist/<slug>/`, subsequent pushes reuse it
7. Organizer, once, in the Sheet (FIRA Actions menu): 🔐 Autoriziraj dozvole →
   ⚙️ Postavi API ključ → 🔧 Instaliraj onEdit trigger (clasp can't create
   triggers) → 📋 Dodaj stupce za fiskalizaciju (adds payment, OIB, Payment Type,
   Tip dokumenta, AKCIJA checkboxes — skips existing ones)

Payment amounts may have up to 2 decimals (`56.62`, or text `56,62`).

## Day-to-day

```bash
npm run build:gas               # rebuild all events
npm run push:gas -- <slug>      # rebuild + push one event to its linked GAS project
```

## Prereqs for clasp

```bash
npm install -g @google/clasp
clasp login
```

Plus enable **Google Apps Script API** at
<https://script.google.com/u/0/home/usersettings>.

## In the GAS UI (after first push)

1. Reload the bound Sheet — `FIRA Actions` menu appears
2. `FIRA Actions → ⚙️ Postavi API ključ`
3. `FIRA Actions → 📋 Dodaj stupce za fiskalizaciju`
4. For split-payment events: `FIRA Split Payment → 📋 Dodaj stupce za split payment`
5. Triggers → `+ Add Trigger` → function `onCheckboxEdit`, source
   `From spreadsheet`, type `On edit`
   (Apps Script API does not allow installable triggers via clasp;
   this step is manual or done by a one-shot installer function in `Mapping.gs`.)
